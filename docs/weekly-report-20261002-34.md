# 이번 주 리포트 · 20261002-34

- 계산(activity.mjs `weeklyReport`): 이번 주 = 월요일~오늘, 비교 = 지난주 월요일~지난주 같은 요일. 기기 시간대의 달력 날짜 기준
  - 운동: 취소하지 않은 세트가 있는 회차 중 시작 시각이 범위 안인 것
  - 운동 시간: 회차 시작부터 마지막 세트까지(분). `endedAt`은 쓰지 않음(종료를 늦게 눌러도 늘지 않게)
  - 세트·볼륨: 세트를 실제로 한 날짜 기준(`dailyActivity`, 주간 볼륨과 같은 값). 덤벨 ×2, 취소 세트 제외
  - 신기록: `recordSets`(records.mjs). 모든 세트를 시간순으로 훑어, 같은 종목·장비의 이전 모든 세트보다 추정 1RM이 높고 그 종목을 한 다른 회차가 이미 있을 때 신기록. 저장 시 알림(`findRecord`)과 같은 규칙
- 요약 문장(`reportSentence`): 숫자만으로 만든 한 문장. 운동이 없거나 지난주 기록이 없을 때 문장이 따로 있음. 조언은 넣지 않음
- 화면: 기록 탭 첫 섹션 ‘이번 주 리포트’. 요약 문장, 4개 수치(모바일 2열, 태블릿 이상 4열)와 아래 ‘지난주 N’ 비교, 이번 주 신기록 최근 3개(트로피 아이콘). 비교 범위 설명은 ⓘ
- 저장 형식, JSON 백업, CSV, NAS 백업 서버 변경 없음

검증: activity 테스트 2개, records 테스트 1개 추가, 전체 PWA 테스트 109개와 백업 서버 테스트 12개 통과. 브라우저에서 이번 주 1회·지난주 같은 기간 2회, 볼륨 27% 감소, 신기록 2개 표시와 375px에서 가로 스크롤 없음 확인.
