# NAS 자동 백업 · 20261002-30

- 설계: `docs/nas-auto-backup-design.md` (B안, 백업 전용 컨테이너)
- 서버: `deploy/nas/backup-server/server.mjs`, `backup-core.mjs`. Node 표준 라이브러리만 사용. 저장소에서는 `domain.mjs`가 `pwa/domain.mjs`를 다시 내보내고, NAS 패키지에는 `pwa/domain.mjs` 사본이 들어감
- 앱: `pwa/nas-backup.mjs`(요청·해시·응답 해석), `pwa/db.mjs`의 `nasBackup` 키(토큰, 마지막 전송 시각·해시, 오류). `main` 레코드와 JSON 백업 형식은 그대로
- 보내는 시점: 기록 저장 3초 뒤(운동 중이면 건너뜀), 앱을 열 때, 다시 온라인이 될 때, ‘지금 백업’. 마지막으로 보낸 내용과 같으면 보내지 않음
- 409(급감)는 확인 창으로 묻고, 취소하면 같은 내용으로는 다시 묻지 않음. 이후 기록이 NAS 백업과 같아지면(복원 등) 경고를 지움
- 화면: 기록 탭 ‘백업 · 복원 · 초기화’ 안 NAS 자동 백업 영역. 상태 배지(백업됨 / 백업 실패 / 백업 중 / 백업 전)는 글자를 포함. 자동 백업 성공은 토스트 없이 상태 줄만 바뀌고, 자동 실패는 같은 이유로 하루 한 번만 알림

검증: 서버 테스트 12개, 앱 모듈 테스트 6개 추가, 전체 107개 통과. 패키지에서 꺼낸 서버를 따로 실행해 401 / 200 / 201 확인. 로컬 테스트 서버(정적 파일 + 백업 처리기)로 브라우저에서 잘못된 토큰, 연결, 자동 백업, 전체 삭제 후 급감 확인, NAS에서 복원까지 확인. 375px에서 가로 스크롤 없음.
