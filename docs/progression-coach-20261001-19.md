# 자동 증량 코치 · 20261001-19

- 운동 화면 목표 카드 아래에 “오늘은 72.5kg 도전?” 제안 카드 표시
- 비교 대상: 현재 운동을 제외한 가장 최근의 같은 이름·장비 종목(취소하지 않은 세트가 있는 것)
- 조건: 계획 세트 수(자유 운동은 기록한 세트 전부)만큼 목표 횟수 이상 달성
- 기준 중량: 목표 횟수를 채운 세트 중 계획 세트 수만큼 들어 올린 가장 무거운 실제 중량. 워밍업 세트와 받아쓰기로 바뀐 중량을 반영
- 증량 폭: 바벨 2.5kg · 덤벨 1kg · 머신 5kg (`PROGRESSION_STEP`)
- 제안하지 않는 경우: 오늘 첫 세트를 이미 기록함, 오늘 중량이 이미 제안 이상, 오늘 목표 횟수가 지난번보다 많음, 2000kg 초과
- ‘올리기’는 진행 중 운동의 목표 중량만 변경하고 루틴 템플릿은 유지. ‘유지’는 메모리에만 기억
- 저장 형식, JSON 백업, CSV 변경 없음. 배포 파일에 `progression.mjs` 추가

검증: progression 테스트 9개 및 전체 PWA 테스트 54개 통과.
