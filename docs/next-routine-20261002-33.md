# 다음 차례 루틴 · 20261002-33

- 계산(workout-guide.mjs):
  - `routineLastDone(routines, sessions)`: 루틴별로 그 루틴으로 시작했고(`session.routineId`) 취소하지 않은 세트가 하나 이상 있는 가장 최근 회차의 시작 시각. 삭제된 루틴과 자유 운동은 무시
  - `nextRoutine(routines, sessions)`: 루틴 2개 미만이거나 루틴 기록이 하나도 없으면 null. 한 번도 안 한 루틴이 있으면 목록 순서상 첫 번째, 없으면 마지막 운동이 가장 오래된 루틴
  - `daysAgo(iso, now, timeZone)`: 기기 시간대의 달력 날짜 차이(0 오늘, 1 어제)
- 화면(오늘 탭, 진행 중인 운동이 없을 때):
  - 선택한 루틴이 다음 차례가 아니면 카드 위쪽에 연한 Primary 줄로 ‘다음 차례’ 배지(repeat 아이콘), 루틴 이름, ‘마지막 운동 N일 전’ 또는 ‘아직 하지 않은 루틴’, ‘선택’ 버튼. 주요 동작(운동 시작)은 그대로 하나
  - 선택한 루틴이 다음 차례면 계획 제목 옆에 ‘다음 차례’ 배지
  - 계획 요약에 ‘마지막 N일 전’ 추가. 기준 설명은 카드 제목 옆 ⓘ
- 선택을 자동으로 바꾸지 않음(앱을 열기만 해도 데이터가 바뀌지 않도록). 저장 형식, JSON 백업, CSV, NAS 백업 서버 변경 없음

검증: workout-guide 테스트 4개 추가, 전체 PWA 테스트 106개와 백업 서버 테스트 12개 통과. 브라우저에서 하체 5일 전·상체 2일 전·등 미수행일 때 다음 차례 ‘등’, 선택 후 배지 이동, 고른 루틴의 마지막 운동일 표시, 375px에서 가로 스크롤 없음 확인.
