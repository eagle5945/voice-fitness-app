# 추천 루틴 · 20261002-38

- 모듈: `pwa/routine-recommender.mjs`(순수 함수). `QUESTIONS`(5개), `askLifts`, `pickProgram`, `buildProgram`, `recommend`
- 질문: 경험(처음/6개월~2년/2년 이상), 주 횟수(2/3/4/5+), 목표(근력/근비대/건강·체력), 시간(45/60/90분), 장비(바벨까지/덤벨·머신만). 경험 6개월 이상 + 바벨이면 선택 질문으로 스쿼트·벤치·데드리프트 5회 무게(20~500kg, 비워도 됨)
- 프로그램 선택(`pickProgram`): 처음 또는 주 2회 → 전신 기초 / 주 3회 + 근력 → 5×5 A/B / 주 3회 그 외 → 전신 A/B / 주 4회 → 상·하체 / 주 5회+ → PPL. 두 번째 후보: 전신 기초↔전신 A/B, 5×5↔전신 A/B, 상·하체↔PPL
- 구성(`buildProgram`): 하루 종목은 우선순위 목록에서 시간에 따라 4·5·6개. 세트×횟수는 목표별(근력 복합 5×5·보조 3×8, 근비대 4×8·3×12, 건강 3×12·2×15). 5×5는 바벨 종목 5×5, 데드리프트 1×5, 그 외 보조 규칙. 덤벨·머신만이면 바벨 종목을 대체(스쿼트→레그 프레스, 벤치→덤벨 벤치프레스, 데드·루마니안→덤벨 루마니안, 오버헤드→덤벨 숄더 프레스, 로우→시티드 케이블 로우)하고, 대체로 겹친 종목은 다음 종목으로 채움
- 시작 중량: 5회 무게 × 0.9/0.8/0.7(목표별), 2.5kg 단위, 바벨 최소 20kg. 오버헤드는 벤치의 60%, 로우는 75%, 루마니안은 데드의 60%를 기준으로. 입력이 없으면 바벨 20·덤벨 6·머신 20kg, 행잉 레그 레이즈 0kg
- 종목 이름은 부위 추정(`guessPart`)과 3대 합계 판별이 바로 알아보는 이름. 모든 조합(주 횟수 4 × 목표 3 × 장비 2 × 시간 3, 추천·두 번째 후보)이 `saveRoutine`을 통과하고 종목이 겹치지 않으며 부위가 분류되는지 테스트
- 화면: `recommend-dialog`(모바일 하단 시트). 한 화면에 질문 하나, 답은 큰 버튼(선택 시 테두리·체크·aria-pressed), 진행 막대와 ‘이전’. 결과에 프로그램 이름, 답 요약, 기준 ⓘ(의학적 조언 아님 포함), 루틴별 미리보기, ‘다른 추천 보기’·‘이 루틴으로 시작’·‘다시 답하기’. 추가하면 첫 루틴을 오늘 루틴으로 선택하고 오늘 화면으로 이동
- 들어가는 곳: 오늘 화면 빈 상태와 루틴 탭 빈 상태의 ‘추천 받기’(주요 동작) + ‘직접 만들기’, 루틴 탭 제목 옆 ‘추천 받기’
- 저장 형식, JSON 백업, NAS 백업 서버 변경 없음. 답변은 저장하지 않음

검증: 추천 테스트 9개 추가, 전체 PWA 테스트 128개와 백업 서버 테스트 13개 통과. CSP 헤더를 붙인 로컬 서버에서 질문 흐름(선택 질문 포함·건너뛰기·잘못된 무게 안내), 5×5 결과(90/72.5/55kg), 다른 추천 후 추가(루틴 2개, 오늘 화면 이동), 덤벨·머신 PPL, 375px 결과 화면과 버튼 44px, 콘솔 오류 없음 확인.
