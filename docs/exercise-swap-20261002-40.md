# 대체 운동 · 20261002-40

- 찾기(`substitutesFor(name, { equipment, avoid })`, routine-recommender.mjs): 라이브러리(66개)에 있는 이름이면 같은 슬롯(같은 동작)을 먼저, `RELATED` 슬롯(비슷한 동작: squat → lunge·hinge, pushH → chestIso·pushV 등)을 다음에. 없는 이름이면 `guessPart`로 같은 부위, 부위도 모르면 빈 목록. 장비 필터(바벨 / 덤벨 / 머신·케이블 / 맨몸·철봉), 관절 부담 제외(허리·무릎·어깨)
- 시작 무게: 같은 이름·장비의 지난 기록(`findPreviousExercise`) → 현재 운동과 같은 리프트 기준이 있으면 비율로 추정(`estimateFrom`, 덤벨 1kg·바벨 2.5kg 단위) → 기본값(`defaultWeight`: 바벨 20, 덤벨 6, 머신·케이블 20, 맨몸 0)
- 운동 중 교체(`swapExercise`, domain.mjs): 유효 세트가 없으면 같은 id로 이름·장비·무게만 교체. 세트가 있으면 원래 운동은 한 세트 수로 계획을 줄이고, 대체 운동을 바로 뒤에 남은 세트 수(최소 1)로 추가하고 현재 종목으로 선택. 원래 운동의 기록·1RM·자동 증량은 섞이지 않음
- 루틴 반영(`swapRoutineExercise`): 회차가 루틴에서 시작했고 ‘루틴에도 반영’을 고르면 루틴에서 같은 이름·장비의 운동을 대체 운동으로 바꿈(세트·횟수 유지, 무게는 시작 무게). 오늘 선택한 루틴은 바꾸지 않음. 원래 운동을 못 찾으면 루틴은 그대로 두고 알림
- 루틴 편집 창: 행의 ⇄에서 고르면 그 행의 이름·장비·무게 입력칸만 바꿈(저장은 기존 ‘루틴 저장’)
- 화면: `swap-dialog`(모바일 하단 시트). 장비 칩, 관절 부담 제외 칩, 같은 동작 / 비슷한 동작 / 같은 부위 묶음, 각 운동에 장비·지난 기록 또는 추정·관절 부담 배지(글자 포함). Lucide `arrow-left-right` 아이콘 추가
- 저장 형식, JSON 백업, CSV 변경 없음

검증: domain 테스트 3개, 추천 모듈 테스트 3개 추가, 전체 PWA 테스트 140개와 백업 서버 테스트 13개 통과. CSP 헤더를 붙인 로컬 서버에서 운동 중 교체(벤치프레스 2세트 후 덤벨 벤치프레스로, 계획 4세트 → 2 + 2, 루틴 반영), 루틴 편집 창 교체, 장비·관절 필터, 지난 기록과 추정 무게 표시, 375px 화면, 콘솔 오류 없음 확인.
