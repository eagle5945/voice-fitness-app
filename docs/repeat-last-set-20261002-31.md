# 직전 세트 반복 · 20261002-31

- 기준 세트: `lastSetOf(exercise)`(dictation.mjs). 현재 운동 회차의 현재 종목에서 취소하지 않은 마지막 세트. 지난 회차 기록은 쓰지 않음
- 버튼: 운동 화면 기록 버튼 묶음의 세 번째 줄 ‘{중량}kg × {횟수}회 다시’(Lucide `repeat` 아이콘 추가). 계획 세트를 모두 채운 뒤에는 기존처럼 ‘추가 세트 기록’만 보임
- 저장: 누르면 바로 `addSet`(source `manual`). 버튼마다 렌더링 시 만든 inputId를 쓰므로 연달아 눌러도 한 번만 저장. 저장 알림에 ‘취소’(cancelSet) 버튼, 7초 표시. 신기록 알림은 직접 입력과 같음
- 받아쓰기: `isRepeatPhrase`(parser.mjs)가 숫자 없는 반복 표현만 인식. 숫자 해석보다 먼저 검사해 “한 번 더”가 1회로 읽히지 않게 함. “다시 12회”처럼 숫자가 있으면 반복 표현이 아님. 첫 세트 전이면 ‘no-previous’로 저장 불가 안내
- 저장 형식, JSON 백업, CSV, NAS 백업 서버 변경 없음

검증: parser 1개, dictation 4개 테스트 추가, 전체 PWA 테스트 100개와 백업 서버 테스트 12개 통과. 브라우저에서 버튼 두 번 연속 클릭 시 1세트만 저장, 취소 동작, 받아쓰기 “한 번 더” 미리보기와 저장, 375px에서 버튼 높이 44px·가로 스크롤 없음 확인.
