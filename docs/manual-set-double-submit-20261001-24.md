# 직접 입력 중복 저장 방지 · 20261001-24

- 문제: 세트 직접 입력 창은 저장할 때마다 새 입력 ID를 만들고 저장 중에도 버튼이 살아 있어, 빠른 두 번 탭이 같은 세트를 두 번 기록할 수 있었음
- 저장 중 잠금: 저장·세트 취소 처리 동안 창의 버튼과 입력칸 비활성화, 닫기 버튼·Esc 무시
- 입력 ID: 창을 열 때 한 번 생성해 재제출 시 `addSet`의 기존 inputId 중복 무시 규칙이 동작
- 수정·세트 취소 흐름은 그대로. 저장 형식 변경 없음

검증: 브라우저에서 저장 4회 연속 제출 → 세트 1개만 저장, 다음 입력·수정·세트 취소 정상, 콘솔 오류 없음. 전체 PWA 테스트 88개 통과.
