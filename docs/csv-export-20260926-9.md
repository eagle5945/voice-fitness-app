# CSV 내보내기 · 20260926-9

- 기록 화면에 CSV로 내려받기 버튼 추가. JSON 백업·복원 유지.
- 유효 세트 한 행씩 내보내며 취소 세트는 제외하고 수정된 중량·횟수를 사용합니다.
- 운동 시작/기록 시각은 Asia/Seoul. 장비별 중량 기준과 입력 방식을 포함합니다.
- UTF-8 BOM, CRLF, 쉼표/따옴표/줄바꿈 이스케이프 및 운동명 수식 실행 방지 처리.
- CSV는 조회용이며 JSON 백업 시각을 갱신하지 않습니다.
- 새 csv 테스트의 모듈 부재 실패를 확인한 뒤 구현. PWA 전체 39개 테스트 통과.
- 로컬 브라우저에서 기존 2세트 유지, CSV/JSON 버튼 표시, CSV 클릭 후 내보내기 안내 표시, JSON 백업 시각 유지 확인.
- iPhone 파일 앱 저장과 실제 Excel 열기는 이 개발 환경에서 확인하지 않았습니다.
- NAS 사이트 백업 위치: 로컬 `.env`의 `BACKUP_CSV_DIR` 참조.
- 정적 파일만 배포. 공개 HTTPS의 app.mjs/csv.mjs/index.html/sw.js 해시가 로컬과 일치함을 확인했습니다.
- 서비스 워커 voice-fitness-v15. 새 CSV 모듈을 오프라인 캐시에 포함합니다.
