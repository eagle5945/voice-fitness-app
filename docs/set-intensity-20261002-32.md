# 세트별 강도 % · 20261002-32

- 계산: `referenceOneRepMax(sessions, exercise, session)`(records.mjs). 해당 회차보다 먼저 시작한 회차에서 같은 종목·장비(`sameExercise`)의 취소하지 않은 세트 중 최고 추정 1RM(Epley). 기록 상세에서 과거 회차를 볼 때도 그 회차 이전 기록만 씀
- 강도: `intensityOf(weight, reference)` = round(중량 ÷ 기준 × 100). 100%를 넘을 수 있음(기준보다 무거운 저반복 세트)
- 단계(`INTENSITY_LEVELS`, 앱 자체 기준): <50 워밍업 · 50 가벼움 · 60 보통 · 70 중강도 · 80 고강도 · 90+ 최대. 번핏의 6단계 기준은 공개되지 않아 따르지 않음
- 배지 색: 80% 이상 warning, 60~79% primary, 그 아래 neutral. 항상 ‘77% 중강도’처럼 글자 포함
- 대상: 바벨·덤벨. 머신은 기구마다 표시 중량이 달라 제외. 덤벨은 한 손 중량끼리 비교하므로 그대로 사용
- 화면: 목표 카드 ‘1RM 대비’ 줄(ⓘ에 계산식·기준 1RM 값·단계), 이번 종목 기록·기록 상세 세트 표의 ‘강도’ 열. 기준이 없으면 열 자체를 숨김
- 세트 표 반응형: `.set-table` 래퍼에 container query(520px 이하)로 한 줄 목록 적용. 데스크톱 2단 카드에서 셀이 세로로 꺾이던 문제를 함께 해결. 목록에서는 강도 배지를 둘째 줄로 내려 수정·삭제 버튼과 겹치지 않게 함
- 저장 형식, JSON 백업, CSV, NAS 백업 서버 변경 없음

검증: records 테스트 2개 추가, 전체 PWA 테스트 102개와 백업 서버 테스트 12개 통과. 브라우저에서 이전 회차 100kg×5(기준 116.7kg) 대비 60kg 51% 가벼움 / 90kg 77% 중강도 / 100kg 86% 고강도, 머신 미표시, 첫 회차 기록 상세에 강도 열 없음, 375 · 768 · 1059px에서 가로 스크롤 없음, 주간 볼륨 표 스타일 유지 확인.
