# 음성 문장 해석 수정 — 20260926-7

- 재현: 키로/키로그램을 무시해 설정 중량으로 대체, 한글 숫자 앞 단어까지 포획해 해석 실패, 회입니다/회했어요 실패.
- 수정: 수사와 단위를 분리해 읽고 단위 별칭·일반 종결 표현을 지원한다. 명시된 중량을 해석하지 못하면 설정 중량으로 대체하지 않는다.
- 실패 진단: 저장 없이 전사 원문(HTML 이스케이프)과 전체/NAS 처리시간을 표시한다. 원문은 화면 메모리에만 남으며 새 요청/화면 전환으로 초기화된다.
- 검증: 기존 테스트 포함 40개 통과. 별도 로컬 포트의 모의 녹음/STT 응답으로 실패 원문 및 시간 표시, HTML 문자 안전 표시, 실패 뒤 재입력, 설정 10kg에서 발화 70kg×20회 확인 및 수동 저장을 브라우저에서 확인했다.
- 배포: 기존 SSH 키로 배포 계정 접속 성공(로컬 `.env`의 `NAS_SSH_USER`). NAS 화면 파일(app.mjs/parser.mjs/index.html/sw.js)과 README만 갱신했다. Hermes 및 STT 컨테이너 재시작 없음.
- 백업 위치: 로컬 `.env`의 `BACKUP_PARSER_DIR` 참조.
- 배포 검증: NAS 내부 PWA 서비스 상태 available=true. 공개 HTTPS 주소의 index.html/parser.mjs/app.mjs/sw.js SHA-256이 로컬 수정본과 일치한다. SW 캐시는 voice-fitness-v13이다.
- 미확인: iPhone 실제 발화 인식률과 속도 개선. 기존 실패 3건의 원문은 확보하지 못했으므로 모두 동일 원인으로 단정하지 않는다. 표시되는 전사문과 전체/NAS 시간을 바탕으로 후속 STT 병목을 조사한다.

로컬 모의 UI 검증은 node scripts/verify_voice_ui.mjs 실행 후 http://127.0.0.1:8877 에서 진행한다. 이 서버는 배포 패키지에 포함되지 않는다.
